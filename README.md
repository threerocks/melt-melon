# 软西瓜 · 果冻工坊

水果软体合成小游戏，使用原生 Canvas，全部资源内嵌在一个 HTML 文件中。

当前版本：V4，增强大水果碰撞时的压缩、回弹和余晃，并保留比分区域文字重叠修复。

## 游玩

[打开当前版本](https://threerocks.github.io/melt-melon/) · [对比 V3](https://threerocks.github.io/melt-melon/v3.html)

下载后打开 `index.html` 也可离线游玩。

移动鼠标或使用方向键选择落点，点击或按 Enter 投放水果。相同水果接触后合成；使用“揉软一下”改变堆叠。页面提供慢镜头、逐帧查看和软体物理体验。

## 发布

GitHub Pages 使用 `main` 分支的根目录，入口为 `index.html`，无需构建。
